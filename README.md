# Simple Interest Calculator

A Bash script designed to calculate simple interest based on principal amount, annual interest rate, and time period in years.

## Description
Simple interest is a quick and easy method of calculating the interest charge on a loan or investment. This script takes three user inputs:
- **Principal Amount**: The initial sum of money.
- **Rate of Interest**: The annual interest rate (in percent).
- **Time Period**: The duration in years.

It calculates simple interest using the formula:
$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$
